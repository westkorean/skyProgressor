# Pet texture data sources

`petTextures.json` contains the preserved baseline mappings originally derived
from:

- Default pet heads: SkyCrypt `PET_DATA` — https://raw.githubusercontent.com/SkyCryptWebsite/SkyCrypt/master/src/constants/pets.js
- Pet skins: Hypixel SkyBlock items resource — https://api.hypixel.net/v2/resources/skyblock/items

SkyCrypt is licensed under the MIT License:
https://github.com/SkyCryptWebsite/SkyCrypt/blob/master/LICENSE

`petTextures.generated.json` is the current overlay generated by
`scripts/updatePetTextures.ts` from:

- Hypixel SkyBlock items resource — https://api.hypixel.net/v2/resources/skyblock/items
- Official Hypixel Wiki API fallback — https://wiki.hypixel.net/api.php
- Hypixel SkyBlock Fandom fallback — https://hypixel-skyblock.fandom.com/api.php

The official Wiki was shut down in July 2026 and currently redirects its API
to the shutdown announcement. The updater records that source failure and does
not invent or import unverified Wiki mappings.

Fandom fallback mappings are extracted from file-page `HeadRender` template
source, never from the rendered PNG. For example, the Frog mapping comes from:
https://hypixel-skyblock.fandom.com/wiki/File:Frog_Pet.png

`petCatalog.generated.json` contains the broader pet and skin catalog, including
display names, pet associations, Wiki image-file names, release/acquisition
metadata when available, exact source URLs, and verification timestamps. Fandom
records without a verified in-game skin ID use a `FANDOM:` catalog key and are
not used for runtime `pet.skin` resolution until an authoritative ID is found.

Legacy pet skins are imported from SkyCrypt's MIT-licensed constants:
https://raw.githubusercontent.com/SkyCryptWebsite/SkyCrypt/development/src/constants/skins-animations.js

The updater extracts only pet IDs, pet-skin IDs, and verified
`textures.minecraft.net/texture/<hash>` hashes. `mc-heads.net` is used only to
render already verified hashes.
